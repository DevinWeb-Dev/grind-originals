# GRIND ORIGINALS — Interactive Jersey Archive

This is the Ashen Press Three.js r181 art-book renderer adapted into a GRIND ORIGINALS jersey design archive.

## Run
Open `index.html` in a modern browser with internet access (Three.js r181 and the authored web fonts load from their original CDN URLs).

## Interactions
- Hover/select volumes to focus the book
- Drag to rotate the scene
- Use “Look inside” to reveal the volume's editorial spread
- Use the catalogue menu to select another edition
- Press Escape or click outside to reset

## Content status
All ten jersey illustrations are clearly identified concept placeholders. The edition names and descriptions are concept copy, not official GRIND Originals product specifications or backstories. Replace these with approved garment artwork and brand-approved stories before public launch.

## Implementation
The original Ashen Press renderer, WebGL/shader passes, book geometry, lighting, hover/selection/flip/drag interactions, responsive behavior, and reduced-motion handling are retained. The catalogue data and brand copy are adapted for GRIND ORIGINALS.
